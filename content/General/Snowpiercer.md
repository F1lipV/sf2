**Snowpiercer** is a special weapon in Shadow Fight 2. It is the weapon of the Chronos Set. This weapon wielded by Freeze Jr., main boss of the event. This weapon was obtainable through the Battle Pass during New Year event 2023, by purchasing Premium Pass to unlock VIP rewards.

## Chronos Set\[]

Read More [[Equipment Sets (SF2)]]

All the items of the Chronos Set bring **Time Shift** mythical enchantment. It is necessary to collect the full set to unlock the enchantment. Once all the items of the set are collected, Time Shift will be available, and the player can enchant other equipment with this enchantment.

## Trivia\[]

![[assets/WEAPON_C2_Z5_DRAGON_KNIVES.png|Dragon Set Knives]] ![[assets/WEAPON_C2_Z5_DRAGON_KNIVES.png|Dragon Set Knives]]

![[assets/WEAPON_C2_Z5_DRAGON_KNIVES.png]]

Dragon Set Knives

- Snowpiercer's design is a modified version of the Dragon Knives from the unused Dragon Set.
- This weapon is currently affected by a bug where the player's hurtbox becomes extended to this weapon while using it. This means that players will take damage even if the enemy only hits the weapon's model. The bug is yet to be fixed.
